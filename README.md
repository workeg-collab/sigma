# نظام سيجما للمحاسبة والمقاولات (Sigma Accounting System)
### تطبيق محاسبي مكتبي متكامل لشركات المقاولات وفق معايير القيد المزدوج
**مبني بواسطة Flutter Desktop & SQLite FFI**

---

## 🌟 نظرة عامة (Overview)

نظام **سيجما** هو منظومة محاسبية تنفيذية متكاملة لشركات المقاولات والإنشاءات، تم تطويرها من الصفر كبديل احترافي متكامل لمنظومات الإكسيل المحاسبية المعقدة. 

يعتمد النظام معايير **القيد المزدوج الحقيقي (True Double-Entry Accounting)**، وقاعدة بيانات علائقية معيارية (19 جدولاً مفهرساً)، ومحرك حسابات مستقل يضمن عدم احتساب أي أرصدة من واجهات الاستخدام بل استنتاجها ديناميكياً من واقع القيود المرحلة.

---

## 🚀 المميزات الرئيسية (Core Features)

### 1. المنظومة المحاسبية العامة
* **دليل حسابات شجري متكامل**: يدعم 5 مستويات، وتصنيفات الأصول، الخصوم، حقوق الملكية، الإيرادات، والمصروفات، مع حماية الحسابات ذات الحركات من الحذف واستبدالها بالتعطيل المؤقت.
* **قيود اليومية المزدوجة**: محرر تفاعلي يدعم عدداً غير محدود من الأسطر، وحساب التكلفة الكمية تلقائياً (`الكمية × سعر الوحدة = الإجمالي`)، مع التحقق الفوري من التوازن.
* **حالات القيد الثلاثية**: مسودة (`Draft`)، مرحل (`Posted`)، ملغى مع ذكر السبب وحفظ مسار المراجعة (`Cancelled`).
* **دفتر الأستاذ العام (General Ledger)**: استعراض حركة الحسابات بالرصيد التراكمي مع إمكانية النقر والانتقال المباشر للقيد الأصلي.
* **ميزان المراجعة (Trial Balance)**: بالمجاميع وبالأرصدة مع التحقق التلقائي من التوازن وإظهار شارة الحالة.
* **الأرصدة الافتتاحية (Opening Balances)**: شاشة مخصصة لإدخال وموازنة أرصدة بداية النشاط.

### 2. محاسبة شركات المقاولات المتخصصة
* **محاسبة وتكاليف المشروعات**: تتبع مباشر لتكاليف كل مشروع (مواد، عمالة، مقاولين، معدات، مصروفات موقع، مصاريف عمومية) وحساب مجمل الربح ونسبة هامش الربحية.
* **كشوف حسابات مقاولي الباطن**: شاشة مستقلة لمقاولي الباطن، كشف حساب تفصيلي يوضح المستخلصات المسجلة والدفعات المسددة والرصيد التراكمي اللحظي.
* **البنود التحليلية (Analytical Dimensions)**: 31 بنداً تحليلياً لهندسة التكلفة (خرسانات، حدادة، نجارة، بياض، كهرباء، إحلال، إلخ) مفصولة تماماً عن الوحدات.
* **وحدات القياس (Units of Measurement)**: جدول مستقل لوحدات القياس (طن، م3، متر طولي، مسطح، يومية، فيلا).
* **إدارة الموردين والعملاء**: كشوف حسابات ومطابقات ديون لحظية.

### 3. القوائم والتقارير المالية والسيولة
* **قائمة الدخل (الأرباح والخسائر)**: حساب صافي المبيعات، تكلفة العمليات، مجمل الربح، المصروفات الإدارية، وصافي ربح العام.
* **الميزانية العمومية والمركز المالي**: تحقق صارم من المعادلة المحاسبية `الأصول = الخصوم + حقوق الملكية` وربط أرباح العام بحقوق الملكية.
* **موقف السيولة والصندوق والبنوك**: شاشة متابعة للمقبوضات والمدفوعات والأرصدة المتاحة في الخزائن والحسابات البنكية.

### 4. الأدوات والنظام المؤسسي
* **شاشة تسجيل دخول احترافية**: تسجيل دخول آمن مع اختصارات سريعة للأدوار التجريبية.
* **إدارة المستخدمين والصلاحيات (RBAC)**: 18 صلاحية مفصلة موزعة على 5 أدوار وظيفية.
* **سجل المراجعة والتدقيق (Audit Trail)**: تدوين تلقائي لكافة العمليات الحساسة مع اسم المستخدم والوقت.
* **النسخ الاحتياطي والاستعادة**: تصدير واسترجاع قواعد البيانات بنقرة واحدة مع فحص سلامة البيانات (`Integrity Check`).
* **الاستيراد والتصدير**: تصدير كافة الجداول والتقارير إلى Excel و CSV (مع UTF-8 BOM) والطباعة بصيغة PDF باللغة العربية، بالإضافة إلى استيراد الحسابات والمشاريع من ملفات Excel بعد فحصها وتدقيقها.
* **دعم السمة الفاتحة والداكنة (Light / Dark Modes)**: تبديل سلس وجميل يدعم بيئة العمل الممتدة.

## 🔑 بيانات تسجيل الدخول التجريبية (Demo Accounts)

تم تزويد النظام مسبقاً بحسابات تجريبية لكافة الأدوار للاختبار الفوري من شاشة الدخول:

| الدور الوظيفي | اسم المستخدم | كلمة المرور | الصلاحيات الرئيسية |
| :--- | :--- | :--- | :--- |
| **مسؤول النظام (Admin)** | `admin` | `admin123` | تحكم كامل في المنظومة والإعدادات والنسخ الاحتياطي |
| **رئيس الحسابات (Accountant)** | `accountant` | `acc123` | ترحيل القيود، إقفال الفترات، وإصدار القوائم الختامية |
| **مراجع مالي (Reviewer)** | `reviewer` | `rev123` | فحص القيود، مراجعة الأستاذ والموازين دون حق الحذف |
| **مدخل بيانات (Data Entry)** | `data_entry` | `entry123` | تسجيل مسودات القيود اليومية والمشروعات |

## 🛠️ متطلبات التشغيل والتشغيل (Run & Build)

### 1. المتطلبات:
* Flutter SDK (3.24+ أو 3.44+)
* Dart SDK (3.5+ أو 3.12+)
* macOS / Windows / Linux

### 2. التثبيت والتشغيل:
```bash
# 1. الدخول لمجلد المشروع
cd /Users/POM/Developer/WORKEG/sigma

# 2. جلب الحزم
flutter pub get

# 3. تشغيل الاختبارات للتأكد من سلامة النظام المحاسبي
flutter test

# 4. الفحص الاستاتيكي للكود
flutter analyze

# 5. تشغيل التطبيق المكتبي
flutter run -d macos
```
